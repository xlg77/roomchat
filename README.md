# roomchat

**채널을 만들고, 친구와 이야기하고, GIF·YouTube·효과음까지 함께 나누는 실시간 채팅 커뮤니티.**

[🌐 RoomChat 열기](https://xlg77.github.io/roomchat/) · [전체 기능 안내](FEATURES.md) · [기능 목록 보관본](FEATURE_REGISTRY.md) · [기능 진행표](FEATURE_TRACKER.md)

RoomChat은 웹 브라우저에서 바로 사용할 수 있는 실시간 공개 채팅 서비스입니다. 게스트로 먼저 둘러볼 수 있고, 계정을 만들면 친구·DM·프로필 꾸미기 같은 소셜 기능을 이용할 수 있습니다. PC와 모바일 화면에 맞춘 UI를 제공하며, 데이터와 실시간 통신은 Supabase를 사용합니다.

> **처음 오셨나요?** 위의 서비스 링크를 열고 게스트 닉네임을 정한 뒤 채널에 들어가 보세요. 친구, DM, 프로필 꾸미기 기능에는 계정이 필요합니다.

## 🚀 핵심 기능 자세히 보기

### 방을 만들고 대화 공간을 구성하기
- 게스트와 계정 회원 모두 공개 채팅방을 만들 수 있습니다.
- 상위 채널 안에 하위 방을 만들 수 있습니다. 하위 방 안에 또 다른 방을 중첩하는 방식은 지원하지 않습니다.
- 방 이미지, 즐겨찾기, 방 목록 순서 변경을 지원합니다.
- 일반 방은 최근 메시지 30개를 유지해 저장 공간 사용을 줄입니다. 현재 배포된 데이터베이스에는 관리자가 상위 채널을 만들 때 무제한 기록을 선택하는 예외도 적용되어 있습니다.

### 텍스트와 미디어를 함께 보내기
- 일반 채팅 메시지는 최대 2,000자입니다.
- JPEG, PNG, WebP, GIF, AVIF 이미지를 최대 8MB까지 첨부할 수 있습니다.
- MP4, WebM, MOV 동영상 파일을 최대 500MB까지 첨부하고 채팅에서 인라인 플레이어로 재생할 수 있습니다.
- 데스크톱에서는 이미지 붙여넣기와 미디어 끌어놓기를 지원합니다. 터치 기기에서는 파일 앱/갤러리 선택 UI를 사용합니다.
- YouTube 링크는 일반 링크와 달리 동영상 플레이어로 표시할 수 있고, 화면 설정에서 미리보기를 끌 수 있습니다.
- GIPHY 검색으로 GIF를 골라 방이나 DM에 공유할 수 있습니다.
- MyInstants 사운드보드에서 효과음을 찾고 미리 들은 뒤 채팅 입력창에 붙여 넣을 수 있습니다.

### 친구와 개인 대화하기
- 계정을 만들고 로그인하면 다른 계정에 친구 요청을 보내고 수락할 수 있습니다.
- 프로필에서 소개, 역할, 가입 시기, 사진, 태그 등을 확인할 수 있습니다.
- 글꼴·굵기·닉네임 색을 조정하고, 다른 사람에게는 본인에게만 보이는 메모를 남길 수 있습니다.
- DM에는 텍스트, 이미지, GIF, 이모지, 답장 인용, 읽음 표시, 알림 설정이 있습니다.
- DM 기록 검색은 현재 열린 메시지 일부만이 아니라 데이터베이스 기록을 페이지 단위로 검색하도록 구현되어 있습니다.

### 방을 관리하기
- 방장과 관리자는 권한에 따라 참여자를 1분·5분·하루 동안 내보낼 수 있습니다.
- 관리자는 운영 패널에서 방, 참여자, 메시지를 관리하고 메시지를 고정할 수 있습니다.
- 관리자 인증 배지는 일반 닉네임과 분리되며, 일반 사용자가 이름에 인증 문구를 넣어 관리자 배지를 가장하지 못하도록 서버 검사가 있습니다.

## 🔐 개인정보와 보안 설계

- 계정은 이메일 주소 대신 로그인용 닉네임과 비밀번호를 사용합니다. 로그인용 닉네임과 채팅 화면의 표시 닉네임은 별도로 관리합니다.
- 비밀번호 검증과 계정 생성은 Supabase Auth 및 서버 측 Edge Function을 거칩니다.
- 브라우저에는 Supabase 공개용 publishable key만 두고, service-role 비밀 키는 공개 클라이언트에 포함하지 않는 구성을 사용합니다.
- 메시지·프로필·태그 등의 데이터 접근은 RLS와 권한을 확인하는 RPC 함수에 의존합니다.
- 공개 채팅방의 메시지와 이미지, 프로필의 공개 항목은 공개 채팅 서비스의 특성상 다른 이용자에게 표시될 수 있으므로 민감한 개인정보를 보내지 마세요.

보안 설계 설명은 저장소 소스의 구현을 요약한 것이며, 외부 보안 감사나 모든 브라우저의 취약점 검증을 의미하지는 않습니다.

## 🧑‍💻 저장소를 실행하거나 기여하려면

1. 저장소를 내려받고 GitHub Pages에서 배포할 경우 기본 브랜치의 루트를 사이트 경로로 설정합니다.
2. Supabase 프로젝트에 핵심 스키마와 필요한 기능 마이그레이션을 적용합니다.
3. Supabase Edge Function의 환경 변수와 외부 API 설정을 확인합니다.
4. 브라우저에서 게스트 입장, 계정 가입/로그인, 채널 채팅, 친구·DM, 태그, 이미지, GIF, YouTube, 사운드보드를 각각 시험합니다.

SQL 파일은 작성 시점과 의존 관계가 서로 다릅니다. **루트의 모든 SQL 파일을 순서 없이 한꺼번에 실행하지 마세요.** 현재 배포 DB에는 적용되어 있지만 같은 SQL 파일이 저장소에 아직 포함되지 않은 일부 마이그레이션이 있습니다. 새 Supabase 프로젝트에서 동일한 동작을 재현하려면 [전체 기능 안내](FEATURES.md)의 배포 차이점을 먼저 확인해야 합니다.

## ⚠️ 알아둘 점

- 방의 일반 메시지 검색은 현재 불러온 방 메시지 범위에 한정됩니다. 모든 과거 공개 채팅 기록을 검색하는 기능은 아닙니다.
- 브라우저 알림은 사용자가 권한을 허용하고 웹 앱과 실시간 연결이 활성화되어 있을 때 동작합니다. 앱을 완전히 닫은 뒤에도 알림을 전달하는 서버 푸시 기능은 별도 구성되어 있지 않습니다.
- 효과음의 원격 재생은 각 브라우저의 자동 재생 정책과 MyInstants 파일 접근 상태에 영향을 받습니다. 모든 모바일 기기에서 소리가 반드시 자동 재생된다고 보장하지 않습니다.
- 모바일 레이아웃과 터치 조작 코드는 포함되어 있지만, 기기·브라우저별 실사용 테스트가 모두 끝났다는 뜻은 아닙니다.
- 이 저장소는 현재 배포 서비스의 모든 서버 설정 및 마이그레이션을 완전히 포함하고 있지는 않습니다. 누락된 배포용 SQL/Edge Function 소스의 추적은 개선이 필요합니다.
